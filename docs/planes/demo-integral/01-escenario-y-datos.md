# D01 — Escenario y datos

Demo local `gym-demo`, separado de A/B. Dataset v1: seis rutas activas de ejemplo, una retirada y un borrador; tres sectores y grados V/Font. IDs reservados, snapshots iniciales insertados únicamente si la ruta no existe. No crear usuarios, roles ni actividad; no reescribir ediciones posteriores.

Ilustraciones SVG originales generadas desde coordenadas 2D, registradas por ID y clave R2 v1; claramente etiquetadas, sin fotografías, capturas ni geometría 3D ficticia. Las rutas públicas son ejemplos incompletos compatibles con la lectura de rutas heredadas: no representan publicaciones verificadas. El editor sigue exigiendo captura/cámara/imagen para publicar.

Aceptación: dataset coherente, idempotencia, borrador oculto, referencias estables y ausencia de cambios en A/B. Pendientes físicos y privados permanecen documentados.
